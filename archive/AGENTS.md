# Restricted Documentation Archive

Explicit user permission is required to access content in this directory.
The full policy is in the repository root `AGENTS.md`, which must be read
before entering or searching the archive.

Do not list, search, read, summarize, include, or copy from archived material
without that permission. A general repository/documentation task does not
grant archive access. Use the active mdBook under `docs/` instead.

An authorized migration may move named current files here without reading
existing archived content. Do not remove or weaken this restriction to proceed.
